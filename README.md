# Web API Cursos

API desenvolvida em **C# e .NET** para gerenciamento de cursos, permitindo realizar operações de cadastro, consulta, atualização e exclusão de cursos.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento **Back-end**, com foco na construção de APIs utilizando o ecossistema .NET.

## Tecnologias utilizadas

* C#
* .NET
* SQL Server
* Git e GitHub

## Funcionalidades

A API permite realizar as principais operações de gerenciamento de cursos:

* ✅ Cadastrar cursos
* ✅ Consultar cursos
* ✅ Consultar um curso específico
* ✅ Atualizar cursos
* ✅ Excluir cursos

##  Métodos

| Método   | Descrição
| -------- | -----------------------|
| `GET`    | Lista todos os cursos  |
| `GET(id)`    | Busca um curso pelo ID |
| `POST`   | Cadastra um novo curso |
| `PUT`    | Atualiza um curso      |
| `DELETE` | Exclui um curso        |

## Banco de dados

O projeto utiliza **SQL Server** para armazenamento dos dados para comunicação entre a aplicação e o banco de dados.

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos essenciais de desenvolvimento full stack, incluindo:

-Criação de APIs REST com C# e .NET
-Desenvolvimento de interface utilizando Angular e Bootstrap
-Modelagem e integração com banco de dados utilizando SQL Server
-Implementação de operações CRUD (Create, Read, Update, Delete)
